# YapPilot by Pak Vinsen - Installation Guide

## 📦 Installation Steps

### 1. Extract ZIP File
Extract `YapPilot-v1.2.0.zip` to a permanent location (e.g., `C:\Extensions\YapPilot`)

**IMPORTANT:** Do NOT delete this folder after installation! Chrome needs it to run the extension.

### 2. Open Chrome Extensions Page
1. Open Google Chrome
2. Go to `chrome://extensions/`
3. Or click: Menu (⋮) → Extensions → Manage Extensions

### 3. Enable Developer Mode
Toggle **"Developer mode"** switch in the top-right corner

### 4. Load Extension
1. Click **"Load unpacked"** button
2. Select the extracted folder (`YapPilot-v1.2.0`)
3. Click **"Select Folder"**

### 5. Done! ✅
Extension should now appear in your Chrome toolbar with the yapping logo 🗣️

## ⚙️ Setup & Configuration

### 1. Get License Key
- Join **Yapper Indo Discord**: https://discord.gg/yapper-indo
- Request your license key from Pak Vinsen

### 2. Get GROQ API Key (Free)
1. Go to https://console.groq.com
2. Sign up (free)
3. Create API key
4. Copy the key (starts with `gsk_`)

### 3. Configure Extension
1. Click extension icon in toolbar
2. Click **"Settings"** button
3. Enter your **License Key**
4. Click **"Validate Key"**
5. Enter your **GROQ API Key**
6. Configure automation settings:
   - **Window Mode**: Normal (recommended)
   - **Delays**: Adjust as needed
   - **Actions**: Enable Like/Comment
7. Click **"Save Settings"**

## 🚀 How to Use

### 1. Collect Post URLs
1. Go to X.com (Twitter)
2. Find posts you want to engage with
3. Copy post URLs (e.g., `https://x.com/username/status/123456789`)

### 2. Start Automation
1. Click extension icon
2. Paste URLs (one per line) in the text area
3. Click **"Start Automation"**
4. Extension will automatically:
   - Like posts
   - Generate AI replies
   - Post comments
   - Wait random delays between actions

### 3. Monitor Progress
- Activity log shows real-time progress
- Stop button available to cancel anytime

## 🪟 Window Modes

### Normal (Recommended)
- Opens posts in regular tabs
- Simple and reliable
- Best for most users

### Auto Focus
- Opens new window for automation
- Window pops up when commenting
- Auto-unfocus after comment
- Good for multitasking

### Always On Top
- Small popup window (800x600)
- Always visible
- Best for monitoring

## ⚠️ Important Notes

1. **Keep folder intact**: Do NOT delete the extension folder after installation
2. **License validation**: You must validate license key before first use

4. **Random delays**: Use random delays to avoid spam detection

## 🔧 Troubleshooting

### Extension disappeared after Chrome restart
- Chrome disabled it automatically
- Go to `chrome://extensions/`
- Re-enable the extension

### "License key invalid" error
- Check license key is correct
- Validate key again in Settings
- Contact Pak Vinsen if issue persists

### Automation not working
- Check GROQ API key is valid
- Ensure license key is validated
- Check Chrome console for errors (F12)

### Comments failing
- Use **Normal** or **Auto Focus** window mode
- Ensure delays are reasonable (min 5s)
- Check X.com is not rate-limiting you
